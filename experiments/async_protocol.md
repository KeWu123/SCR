# Draining ingestion queue protocol

Locked before execution. Independently extend original SCR's fixed-cut diagnostic with an actual wall-clock queue that drains after the writer stops. Three seeds11/29/47;1,024 vectors in16 dimensions;250 updates spaced2ms; queue delays0/10/40ms. A single FIFO ingester applies each source commit no earlier than its monotonic-clock ready time. Source versions and index arrays are protected by short implementation mutexes. Query focus is either uniformly selected or the most recently updated row (a declared adversarial fresh-evidence stress case). The updated embedding moves by Gaussian .01 so old/new vectors can remain nearest.

Each episode selects a declared source snapshot, reads its focus row, then compares current async candidates against exact version truth for that snapshot. A stale snapshot admitted at the applied prefix pins a copy of that generation and resolves source history at its commit prefix. Record invalid exact version outputs, actual source-focus read conflicts, backlog, writer/ingestion phase, snapshot age in commits and answer changes. Collect through steady writing, draining, and at least20 reads after the queue empties. Report phase-conditioned rates, not their arbitrary mixture. Post-drain expected backlog0 and version-invalid count0; admitted prefix expected zero invalid at every phase. Timing numbers are measured on the host and are not production claims.

Independent checker reconstructs per-snapshot source truth from the saved immutable commit log and validates every answer key; verifies contiguous applied prefixes, queue completion and post-drain soundness. Every printed summary comes from saved episode records.
